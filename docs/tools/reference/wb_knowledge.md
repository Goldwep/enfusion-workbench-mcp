# wb_knowledge

```text
Search the Arma Reforger modding knowledge base — distilled pattern files covering scripting, audio, weapons, vehicles, AI, UI, game modes, animation, and all other modding domains. Use this before writing EnforceScript code or setting up any Enfusion modding system. Call with query='index' to see all available topics.
```
